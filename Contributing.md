## 🎯 **Cara Berkontribusi**

### ✅ **Tanpa Coding (Mudah Sekali!)**

| Jenis | Cara |
|-------|------|
| ⭐ **Kasih Bintang** | Klik tombol **Star** di pojok kanan atas |
| 🐛 **Lapor Error** | Buka tab **Issues**, tulis detail error |
| 💡 **Saran Fitur** | Buka tab **Discussions**, tulis ide kamu |
| 📝 **Perbaiki Typo** | Edit README.md langsung di GitHub |
| 📢 **Share Repo** | Bagikan ke teman atau komunitas |

### 💻 **Dengan Coding (Pemula Friendly)**

| Level | Ide Kontribusi | File Target |
|-------|----------------|-------------|
| ⭐ Mudah | Tambah provider HP | `sources/phone_db.py` |
| ⭐ Mudah | Tambah platform username | `sources/social_media.py` |
| ⭐⭐ Menengah | Perbaiki bug kecil | `modules/*.py` |
| ⭐⭐ Menengah | Tambah fitur sederhana | `modules/*.py` |
| ⭐⭐⭐ Expert | Fitur baru kompleks | Diskusi dulu via Issues |

## 🚀 **Langkah-Langkah (Coding)**

### 1️⃣ **Fork Repository**
```bash
Buka https://github.com/ruyynn/GhostIntel
Klik tombol Fork (pojok kanan atas)
```
### 2️⃣ Clone ke Komputer
```bash
git clone https://github.com/ruyynn/GhostIntel.git
cd GhostIntel
```
### 3️⃣ Buat Branch Baru
```bash
git checkout -b nama-branch-kamu
# Contoh: git checkout -b tambah-provider
```
### 4️⃣ Edit & Test
```bash
# Edit file yang diperlukan
# Jalankan program untuk test
python ghostintel.py
```
### 5️⃣ Commit & Push
```bash
git add .
git commit -m "Deskripsi singkat perubahan"
git push origin nama-branch-kamu
```
### 6️⃣ Buat Pull Request

Buka GitHub, klik Compare & pull request

Isi judul dan deskripsi

Klik Create pull request

## ❓ Frequently Asked Questions

| Question | Answer |
|---------|--------|
| **I can't code. Can I still contribute?** | Yes! You can help by reporting bugs, improving documentation, suggesting features, or testing the tool. |
| **What if I make a mistake in my contribution?** | No worries. Maintainers will review your pull request and help guide you if something needs improvement. |
| **What is a Pull Request (PR)?** | A Pull Request is how you propose changes to the project. You submit your code and the maintainers review it before merging. |
| **What does "Forking" mean?** | Forking creates your own copy of the repository so you can modify it safely before submitting changes. |
| **How long does review usually take?** | Usually between **1–7 days**, depending on maintainers' availability and the complexity of the changes. |
